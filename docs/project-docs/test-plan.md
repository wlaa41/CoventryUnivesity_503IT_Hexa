# CyberQuiz Test Plan

## 1. Purpose

The purpose of testing is to ensure the CyberQuiz application works correctly and provides a good user experience.

## 2. Testing Objectives

- Check if all features work correctly
- Identify bugs and problems
- Test different browsers
- Test mobile responsiveness
- Ensure accessibility

## 3. Features To Be Tested

### User Features
- Home page loading
- Children mode
- Teens mode
- Adults mode
- Correct answer scoring
- Wrong answer scoring
- Explanation display
- Next question button
- Result page
- Leaderboard
- Guest nickname

### Admin Features
- Add question
- Disable question

## 4. Testing Environment

### Browsers
- Google Chrome
- Microsoft Edge

### Devices
- Desktop
- Mobile (375px)

## 5. Testing Types

### Functional Testing
Checking if features work correctly.

### Browser Testing
Checking if app works in different browsers.

### Mobile Testing
Checking responsiveness on mobile devices.

### Accessibility Testing
Checking if all users can access the app.

## 6. Tools Used

- Google Chrome
- Microsoft Edge
- Chrome DevTools
- Google Lighthouse
- WAVE Accessibility Checker
- Excel

## 7. Expected Result

The application should function correctly without major bugs.
