Kera QB: 3D Quiz Bike Challenge

How to run:
1. Extract the ZIP.
2. Open index.html in Google Chrome or Microsoft Edge.
3. Internet is required the first time because the game loads Three.js from a CDN.

Game features:
- 7-second loading screen: Kera 🍌 for 3.5 seconds and QB for 3.5 seconds.
- 3 modes: Easy, Medium, Hard.
- 10 levels.
- 3-question quiz before every bike stage.
- Bike stage lasts 60 seconds.
- After level 10, the game returns to the home screen.
- 3D bike, road, obstacles, bananas, music/SFX, HUD, pause, mobile controls.
