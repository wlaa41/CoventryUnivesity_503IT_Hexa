# Hexa Quiz Test Plan

## Purpose

This document explains how the team will test Hexa Quiz.

## What to Test

| Area            | What to check                            |
| --------------- | ---------------------------------------- |
| Home page       | Loads correctly and looks attractive     |
| Level selection | Kids, teens, and adults buttons work     |
| Quiz questions  | Correct questions show for each level    |
| Answers         | Correct and wrong answers show feedback  |
| Score           | Score increases only for correct answers |
| Result screen   | Final score appears correctly            |
| Mobile view     | App works on phone screen size           |
| Accessibility   | Text is readable and buttons are clear   |

## Devices

- Laptop
- Mobile phone
- Tablet if available

## Browsers

- Chrome
- Edge
- Firefox if available

## Test Steps

1. Open the frontend.
2. Click Kids Mode.
3. Answer all questions.
4. Check score.
5. Return to home.
6. Repeat for Teens Mode.
7. Repeat for Adults Mode.
8. Test on mobile screen size.
9. Record bugs in bug-report.md.

## Pass Criteria

The prototype passes testing if:

- The app loads.
- All three levels work.
- Questions display correctly.
- Feedback appears after each answer.
- Final score appears.
- No major layout issue appears on mobile.
