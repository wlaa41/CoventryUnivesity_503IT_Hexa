# CoventryUnivesity_503IT_Hexa

## Project Overview

The Cybersecurity Quiz Game is an interactive educational game designed to teach cybersecurity awareness through engaging quizzes presented in a fun storytelling format. Players follow different scenarios and make decisions that help them learn how to stay safe online while enjoying an entertaining experience.

Unlike traditional quiz systems, the game is organized by age groups to ensure that the content is appropriate, relatable, and educational for different audiences.

## Features

- Story-driven cybersecurity challenges
- Age-based quiz categories
  - Children
  - Teens
  - Adults
- Interactive multiple-choice questions
- Instant feedback and explanations
- Educational cybersecurity awareness content
- Engaging and easy-to-use interface

## How the Game Works

Players enter a story-based scenario where they encounter common cybersecurity situations such as:

- Suspicious emails
- Online scams
- Password security challenges
- Social media privacy risks
- Safe internet browsing practices

At key moments in the story, players answer quiz questions that determine the outcome of the scenario while learning cybersecurity best practices.

## Target Audience

### Children
Simple and fun scenarios focused on safe internet use, protecting personal information, and recognizing online dangers.

### Teens
Realistic situations involving social media, online gaming, cyberbullying, phishing, and digital privacy.

### Adults
Workplace security, financial scams, password management, data protection, and safe online communication.
